# Упрощённый технический русский

Скилл помогает ИИ-агенту писать понятные технические тексты на русском: инструкции,
документацию, объяснения, промпты и описания инструментов. Он убирает сложные обороты,
но сохраняет факты, условия, запреты, команды и названия.

Основа — раздел 8 [ГОСТ Р 58049-2017](https://meganorm.ru/mega_doc/norm/gost-r_gosudarstvennyj-standart/12/gost_r_58049-2017_natsionalnyy_standart_rossiyskoy.html).
Адаптации для ИТ и чата отмечены отдельно. Скилл не подтверждает полное соответствие
авиационной документации стандарту.

## Пример

**До:** После одобрения владельца необходимо выполнить перезапуск только тестового сервиса.

**После:** Только после одобрения владельца перезапустите только тестовый сервис.

Оба ограничения сохранены: требуется одобрение, а перезапуск касается только тестового сервиса.

## Установка без работы с терминалом

Откройте чат своего агента, который умеет устанавливать локальные скиллы. Отправьте:

> Установи скилл simplified-technical-russian из https://github.com/yetanotherrepo/simplified-technical-russian.
> Сохрани его вместе с папками references, examples и agents. Если он уже установлен, сначала проверь существующую версию.

Если агент не может установить файлы, скачайте архив через **Code → Download ZIP**
на GitHub. Распакуйте его в каталог скиллов вашего агента под именем
`simplified-technical-russian`. Файл `SKILL.md` должен лежать непосредственно
в этой папке, а не ещё на один уровень глубже.

Для пользовательского каталога Codex путь по умолчанию:
`~/.codex/skills/simplified-technical-russian/SKILL.md`.
Если у вас настроен другой каталог Codex, используйте его каталог `skills`.

## Установка через терминал

Для стандартного пользовательского каталога Codex:

```sh
git clone https://github.com/yetanotherrepo/simplified-technical-russian.git ~/.codex/skills/simplified-technical-russian
```

Если папка уже существует, команда остановится. Не удаляйте её ради повторной установки.

## Первый запрос

В новом чате напишите:

> Используй $simplified-technical-russian. Отредактируй по-русски: «Необходимо осуществить выполнение проверки доступности сервиса».

Ожидаемый результат: «Проверьте доступность сервиса».

Автоматическое применение включено для подходящих задач на русском языке.
Фактический выбор скилла зависит от агента и загрузки его каталога скиллов.
Явный вызов выше позволяет проверить установку.

Для английского текста используйте отдельный STE-скилл. В смешанном документе
русские правила относятся только к русским фрагментам. Для художественного текста
и рекламы этот скилл не предназначен.

## Что входит

- [SKILL.md](SKILL.md) — основные инструкции агента.
- [Связь со стандартом](references/standard.md) — пункты ГОСТ и границы адаптации.
- [Примеры](examples/before-after.md) — правки и случаи проверки смысла.
- [Настройки](agents/openai.yaml) — название и автоматическое применение в Codex.

В пакете нет скриптов, внешних сервисов и словаря, который выдаётся за утверждённую
терминологическую базу. Агент использует словарь проекта, если он предоставлен.
