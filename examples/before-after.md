# Примеры для ИТ-текстов

Это собственные примеры скилла. Они не являются цитатами из стандарта.

| Ситуация | Исходный текст | Результат |
| --- | --- | --- |
| Отглагольная конструкция | Осуществите выполнение проверки доступности сервиса. | Проверьте доступность сервиса. |
| Известный исполнитель | Заявка проверяется администратором. | Администратор проверяет заявку. |
| Условие допуска | После одобрения владельца необходимо выполнить перезапуск только тестового сервиса. | Только после одобрения владельца перезапустите только тестовый сервис. |
| Одновременные действия | Нужно одновременно удерживать Shift и нажать Enter. | Удерживая Shift, нажмите Enter. |
| Неизвестный исполнитель | Файл был удалён; кто его удалил, неизвестно. | Файл удалён. Кто его удалил, неизвестно. |
| Предупреждение | Нельзя удалять каталог, если ещё не проверена резервная копия. | Если резервная копия ещё не проверена, не удаляйте каталог. |
| Точная надпись интерфейса | Необходимо осуществить нажатие на кнопку «Save changes». | Нажмите «Save changes». |
| Код и область действия | Нужно выполнить `kubectl get pods -n staging`, чтобы посмотреть поды в staging. | Выполните `kubectl get pods -n staging`, чтобы посмотреть поды в staging. |
| Сохранение неопределённости | После изменения настройки вход не проверяли. | После изменения настройки вход не проверяли. |

В примере с Shift деепричастие сохраняет одновременность. Замена на два
последовательных шага могла бы изменить действие. Упрощение не требует удаления
всех таких конструкций.

## Проверка выбора языка

- «Напиши runbook по-русски» → применить русский скилл.
- «Отредактируй этот русский README» → применить русский скилл без дополнительного вызова.
- «Напиши инструкцию на английском» → использовать английский STE, даже если запрос написан по-русски.
- «Сделай русскую и английскую версии» → разные правила для соответствующих фрагментов.
- «Напиши рекламный слоган по-русски» → не применять этот скилл.
- «Сохрани дословную цитату и объясни её по-русски» → не менять цитату; редактировать объяснение.

## Проверка сохранения смысла

Исходник: «Можно удалить архив старше 30 дней только после одобрения владельца,
если восстановление из резервной копии проверено. Файлы legal_hold удалять запрещено».

Допустимый результат:

> Архив старше 30 дней можно удалить только после одобрения владельца, если восстановление из резервной копии проверено.
> Файлы legal_hold удалять запрещено.

Сохраняются возможность вместо обязанности, оба условия допуска, строгая граница
возраста и отдельный запрет. Нельзя заменить это командой «Удалите старые архивы».
